# CSN-React-Firebase-Chat-Web-App
This project is a simple real-time chat web application built with React and Firebase. I created it to experiment with building real-time apps and working with cloud databases.

The app allows users to sign in using their Google account, after which they can create their own chat rooms. When a room is created, a unique room ID is generated. Anyone who has that room ID can join the room and start chatting with others inside it.

Messages are stored and synced using Firebase, which means chats update instantly for everyone in the same room without needing to refresh the page.

Features

Sign in with Google authentication

Create your own chat rooms

Join rooms using a room ID

Real-time messaging between users

Built with React + Firebase
Why I Built This

I built this project to practice building a real-time web application, working with authentication, and integrating Firebase as a cloud database with a React frontend.
